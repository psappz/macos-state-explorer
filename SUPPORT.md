# Support

## Getting Help

Use GitHub issues for project support:

- Bug reports for broken behavior.
- Feature requests for proposed improvements.
- Research issues for macOS behavior, traces, or reverse-engineering notes.
- Discussions for open-ended questions.

## Before Opening an Issue

Please include:

- Your macOS version.
- The command you ran.
- What you expected.
- What happened instead.
- Relevant output with personal information removed.

## Safety

Do not post sensitive logs, private paths, account names, hostnames, or device identifiers unless you have reviewed and redacted them.

This project should not ask you to reset TCC, delete caches, unregister apps, or modify macOS system state.
