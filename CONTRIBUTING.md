# Contributing

Thanks for helping improve Open State Diagnostics & Repair Framework.

The repository currently remains named `macos-state-explorer`; that identifier is retained only for repository, package, import-path, and command-context compatibility. Public-facing documentation should use **Open State Diagnostics & Repair Framework**.

## Definition of Done

Every architecture-affecting PR must update docs.

Do not add new Diagnostic Engines until the Chrome Local Network reference case is fully solved. Keep Core free of domain-specific logic and place domain behavior in engines.
